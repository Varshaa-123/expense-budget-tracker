# 01 Project Overview

**Name:** Expense & Budget Tracker

**Objective:** Help a person record income and expenses, group them into categories, set monthly budgets and see where the money goes.

**Problem solved:** People lose track of spending. This app gives a live dashboard with totals, balance, category spending and budget progress.

**Scope of version 1:** one working local application (React + Spring Boot REST API + MySQL). No login, no Docker, no cloud yet.

**Tech:** React, Vite, Axios, Java 21, Spring Boot, Spring Data JPA, MySQL, Postman.
