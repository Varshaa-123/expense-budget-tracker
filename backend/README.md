# Backend: Expense & Budget Tracker API

Spring Boot 3.5, Java 21, MySQL. Runs on http://localhost:8091

1. Set your MySQL password in `src/main/resources/application.properties` (replace `YOUR_PASSWORD`).
2. `mvn spring-boot:run`

Packages: `controller` (HTTP), `service` (business logic), `repository` (database), `entity` (tables), `dto` (JSON shapes), `exception` (error handling).
